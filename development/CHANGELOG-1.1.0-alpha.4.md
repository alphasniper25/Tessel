# TESSEL 1.1.0-alpha.4 — UI and Garage

User-directed requirements: exactly three shop cards; preserve original flat geometric style; compact shop; move player HP onto the tank; tank selection and preview; modular cosmetic garage; earned cosmetic credits; closer camera.

- Three paid card slots, larger title/description contrast, separate rarity label, visible compact Lock and Buy controls, compact healing and refresh row, no extra healing tile. Boss reward choice is shown separately from the shop. Existing economy, mission gating, rarity, weighted families, price locks and readiness rules unchanged.
- Tank-mounted numeric and proportional HP bars for every visible player, including a local-player label in co-op; no top-corner health pips. Existing revive ring remains. Other HUD elements remain.
- Tank Garage on the home screen with preview and saved class selection; same class preview in Play and co-op selection. Four classes retain their gameplay stats; default class hull shapes are circle, square, hexagon and diamond. Original Balanced body is retained. 15 template parts (4 defaults + 11 purchasable) in Body, Turret, Paint and Skin. Preview-before-buy and equip owned options; prices are initial balancing choices. Cosmetic barrel count does not change firing mechanics. Credits = lifetime seconds / 30 (floor) + kills / 10 (floor) + 15 per boss + 100 per campaign completion. Balance subtracts purchased part costs; no real money, no card purchases outside runs, no currency transfer. History erase clears earned credits, not purchased cosmetics. Ownership is local, stored in preferences. No cloud account.
- Shared Canvas TankArt with precomputed geometry, no new image/texture files. Color/shape/barrel/pattern templates; cosmetics stored in 2-byte per-player appearance IDs in lobby messages, snapshots and checkpoints. Existing saves read with default appearance; solo resumed runs use equipped cosmetics. Resumed co-op games retain their saved looks. Original default teammate hexagon remains; class/skin selections are visible across peers. Duels keep existing equal gameplay stats, cosmetics are visual only.
- Camera follows player with 1.12x default and 1.0/1.12/1.25x settings. Arena coordinates, hitboxes, controls and simulation unchanged. Tutorial retains full view. Cropping reduces peripheral visibility, use Full arena for maximum warning range.
- Protocol 17 (old peers incompatible); checkpoint 6 (older checkpoints readable), ledger unchanged. Version code 25. NFC and direct Wi-Fi unchanged. Original MIT attribution retained.
- UI inspiration: Brotato shop lock/reroll mechanics (https://brotato.wiki.spellsandguns.com/Shop); its four-slot layout is explicitly NOT used. No generated concepts or external graphics used.

No production release or signing-key change. Physical display, gameplay balance and real-device multiplayer/NFC require testing. A new CI-generated debug key may differ from the previous test APK, preventing in-place installation; do not uninstall without backing up important test data. Stable signing is needed for subsequent updates.
